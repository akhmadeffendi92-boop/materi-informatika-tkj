Lautan Informasi Digital

Google mengindeks triliunan halaman. Memahami bahwa web terdiri dari berbagai format file adalah kunci untuk menggunakan operator filetype: secara efektif.

  • HTML (Halaman Web Biasa)
  • PDF (Dokumen Resmi/E-Book)
  • PPT/PPTX (Presentasi)
  • DOC/DOCX (Dokumen Teks)

Tips Pencarian Efektif

🎯

Kata Kunci Unik

Jangan tanya "bagaimana cara". Langsung ke inti.

❌ Bagaimana cara instal python
✅ cara instal python windows 11
🙊

Abaikan Tanda Baca

Google mengabaikan titik, koma, tanda tanya. Hemat waktu Anda!

🇬🇧

Gunakan Bahasa Inggris

Untuk hal teknis (coding, error log), database Bahasa Inggris jauh lebih lengkap.

📑

Tab Khusus

Jangan cari gambar di tab 'Semua'. Gunakan tab Gambar, Berita, atau Buku.

Literasi Digital: Anti Hoaks

Checklist Verifikasi

1

Cek Sumber

Apakah domainnya .go.id (pemerintah), .ac.id/.edu (pendidikan)? Blog pribadi (.blogspot) kurang kredibel untuk referensi ilmiah.

2

Cek Tanggal

Informasi teknologi cepat usang. Artikel cara instal Windows XP tidak relevan di 2024.

3

Cross-Check

Jangan percaya satu sumber. Bandingkan minimal 2-3 situs berbeda.

"Kritis sebelum membagikan, Cermat sebelum menggunakan."
